Quick start (you can change anything after)

Text and layout

Clear, rounded sans-serif fonts are easier to decode.

Off-white pages reduce glare. In Word, the colour shows on screen; to print it, save as PDF from here or print on coloured paper.

Language and reading

Swaps about 150 hard words and phrases for plain ones (e.g. approximately → about) and splits very long sentences. It follows fixed rules, not AI, so always read the result. Changes are highlighted in the preview.

    What Adjust Me can't do offline
    • AI rewriting. Properly rewriting text at a lower reading level, or summarising it, needs an AI service on the internet. Adjust Me uses fixed word lists and sentence rules instead.
    • Making new pictures to explain the content. It can add picture cues and resize the pictures already there.
    • Translating into another language.
    • Read aloud. Some computers' voices send text online, so it isn't built in. Use Word's or Edge's own Read Aloud on the downloaded file.
    • Scanned PDFs (photos of pages). Reading text from pictures (OCR) isn't included.
    • Google Docs links. Download the Google Doc as .docx first.
    • Pictures and tables inside PDFs. From a PDF only the text comes across. Use the Word version of a worksheet when you have it.
